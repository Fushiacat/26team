## Описание

## Технические детали

### 1. Обработка ошибок в хендлерах

В каждом хендлере добавить `try/except` для обработки ошибок БД:

```python
try:
    await create_user(...)
except Exception as e:
    await message.answer("Произошла ошибка. Попробуй снова.")
    print(f"Error: {e}")
```

### 2. Краевые случаи

- **Повторная регистрация:** `/start` для существующего пользователя → показать текущую анкету (реализовано в T-003)
- **Пустые анкеты:** валидация полей (реализовано в T-003)
- **Нет анкет для матчинга:** сообщение "Пока нет подходящих анкет" (реализовано в T-005)
- **Короткое имя:** валидация 2-50 символов (реализовано в T-003)
- **Длинное описание:** валидация до 500 символов (реализовано в T-003)

### 3. Обновить README.md

Добавить инструкцию по запуску:

```markdown
# TeamMatch

Telegram-бот для быстрого матчинга участников хакатона.

## Запуск

1. Получи токен у @BotFather
2. Создай файл `.env` (см. `.env.example`)
3. Установи зависимости: `pip install -e ".[dev]"`
4. Запусти: `python main.py`

## Тесты

`pytest`
```

### 4. Финальный ручной прогон

Проверить все сценарии:
1. `/start` → заполнить анкету → сохранить
2. `/me` → проверить отображение
3. `/edit` → изменить имя → проверить
4. `/find` → проверить список анкет
5. Нажать "Связаться" → проверить ссылку

### 5. Проверить .gitignore

Убедиться что `.env` и `data/` в `.gitignore`.
