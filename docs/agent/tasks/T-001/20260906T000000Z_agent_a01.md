# T-001: Настройка проекта

**Владелец:** agent
**Статус:** pending
**Этап PLAN.md:** Этап 1 (подготовка)
**Время:** ~30 мин

## Описание

Настроить инфраструктуру проекта: зависимости, переменные окружения, структуру директорий, точку входа.

## Технические детали

### 1. Обновить `pyproject.toml`
Добавить зависимости:
```toml
dependencies = [
    "aiogram>=3.12,<4",
    "python-dotenv>=1.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=8.0",
]
```

### 2. Создать `.env.example`
```
# Telegram Bot Token — получить у @BotFather в Telegram
# 1. Откройте @BotFather
# 2. Нажмите /newbot
# 3. Введите имя бота (например, TeamMatch Test Bot)
# 4. Введите username бота (например, teammatch_test_bot)
# 5. Скопируйте токен и вставьте ниже
BOT_TOKEN=your_token_here
```

### 3. Обновить `.gitignore`
Добавить строку:
```
.env
data/
```

### 4. Создать структуру директорий
```

src/bot.py
src/config.py
src/db.py

```

### 5. `src/__init__.py` — пустой файл

### 6. `src/config.py`
```python
import os
from dotenv import load_dotenv

load_dotenv()

BOT_TOKEN = os.getenv("BOT_TOKEN")
```

### 7. `src/bot.py`
```python
from aiogram import Bot, Dispatcher
from src.config import BOT_TOKEN

bot = Bot(token=BOT_TOKEN)
dp = Dispatcher()

# Подключение роутеров будет добавлено в T-003, T-004, T-005
```

### 8. `main.py`
```python
import asyncio
from src.bot import bot, dp

async def main():
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())
```
