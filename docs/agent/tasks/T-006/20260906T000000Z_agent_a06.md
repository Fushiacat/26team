## Технические детали

### 1. Текущая реализация (из T-005)

Кнопка "Связаться" уже реализована в `src/handlers/match.py` как inline-кнопка с URL `tg://user?id=<telegram_id>`. Это стандартный подход aiogram — `InlineKeyboardButton(url=...)`.

### 2. Дополнение: callback-хендлер для логирования (опционально)

Если нужно логировать факт нажатия "Связаться":

```python
@router.callback_query(F.data.startswith("contact:"))
async def contact_user(callback: CallbackQuery):
    target_id = int(callback.data.split(":")[1])
    user = await get_user(callback.from_user.id)
    target = await get_user(target_id)
    # Логирование (можно убрать для MVP)
    print(f"Contact: {user['name']} -> {target['name']}")
    await callback.answer("Открываю профиль...")
```

Но для MVP достаточно URL-кнопки без callback.

### 3. Проверка

Убедиться что:
- Ссылка открывает Telegram профиль пользователя
- Кнопка отображается корректно
- Нет ошибок при нажатии
